# 🎮 Hangman Game (Python)

## 📌 Overview

This project is a console-based **Hangman Game** developed using Python as part of the **Code Alpha Python Developer Internship**.

The game randomly selects a word from a predefined list, and the player must guess the word one letter at a time before running out of lives.

---

## ✨ Features

* 🎯 Random word selection
* 🔤 Dynamic hidden word display
* ❤️ Six lives for incorrect guesses
* 🔁 Interactive console gameplay
* ✅ Correct and incorrect guess validation
* 🏆 Win and lose conditions
* 📋 Tracks guessed letters throughout the game

---

## 🛠️ Technologies Used

* Python
* Random Module
* Lists
* Strings
* While Loops
* For Loops
* Conditional Statements

## 🚀 How to Run

1. Clone the repository.
2. Open the project in any Python IDE or terminal.
3. Run the Python file.
4. Start guessing letters and try to reveal the hidden word before your lives run out!
